Movie Performance Analytics Dashboard & Data Pipeline

This is an end-to-end analytics project that shows how raw public movie data can be turned into business-ready reporting. Raw CSV files are staged in Amazon S3 and loaded into Snowflake. dbt then models the data into source, dimension, fact, and mart models. Python supports genre cleanup, and Power BI pulls from Snowflake to visualize movie revenue, ratings, genres, budgets, and return on investment.

Solution Architecture

The platform follows a source-to-dashboard analytics workflow. Raw movie CSV files are stored in Amazon S3 and loaded into Snowflake through a Snowflake stage. dbt then transforms the raw data into clean reporting models across source, dimension, fact, and mart layers. Python supports genre cleanup and ordering logic. Power BI connects to the final Snowflake models for reporting.

  • Amazon S3 stores the raw movie CSV files before they are loaded into Snowflake.
  • Snowflake stores the raw source tables and the dbt-built reporting models.
  • dbt transforms the raw data into analytics-ready tables through source, dimension, fact, and mart layers.
  • Python supports genre cleanup so genre reporting is easier to compare.
  • Power BI consumes the final Snowflake models for dashboard reporting.

Transformation Layer

After Snowflake loads the source CSV files, dbt transforms the raw records into analytics-ready models. The transformation layer is organized into source, dimension, fact, and mart folders so data cleaning, reusable modeling logic, and final reporting outputs remain separated.

  • Source models standardize raw fields and prepare clean references for downstream logic.
  • Dimension models create reporting entities for movies, users, movie tags, and genome tags.
  • Fact models organize ratings, genome scores, movie metadata, revenue, budget, and return-on-investment data.
  • Mart models provide stable reporting datasets for Power BI.
  • dbt tests and documentation make important model relationships and transformation logic easier to review.

The fct_ratings model is configured as an incremental model. This lets the pipeline process new rating records during future runs instead of rebuilding the full ratings table every time.

Python Enrichment

Python supports the Movie Performance pipeline by cleaning and organizing genre data before reporting. This step helps make genre comparisons more consistent in the Power BI dashboard.

  • Uses pandas to support genre cleanup and ordering logic.
  • Prepares genre data for easier comparison across revenue, rating, budget, and return-on-investment metrics.
  • Improves dashboard readability by making genre categories more consistent.

Dashboard and Reporting Layer

The Power BI reporting layer connects to Snowflake models and organizes movie performance into the following dashboard views:

  • Executive KPI cards track movie count, average rating, average revenue, average budget, and average return on investment.
  • Revenue reports compare actual revenue and projected revenue by decade.
  • Genre reports show revenue contribution and profit performance by genre.
  • Movie-level reports show title, genre, rating, revenue, budget, and return on investment.
  • Filters support decade, genre, rating range, and movie title analysis.
