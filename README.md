# Cody Stoerck Portfolio Website

This repository contains the static GitHub Pages portfolio website for Cody Stoerck.

## Website Structure

```text
.
├── index.html              # Portfolio homepage
├── onyx-auto.html          # Featured Onyx Auto case study page
├── styles.css              # Site-wide styling
├── 404.html                # Basic GitHub Pages 404 page
├── .nojekyll               # Prevents GitHub Pages from processing with Jekyll
└── assets/                 # Screenshots, resume PDF, and certification files
```

## Deployment Instructions

1. Create or open the GitHub Pages repository, usually named `CStoerck.github.io`.
2. Upload all files and folders from this package to the root of the repository.
3. In GitHub, go to **Settings → Pages**.
4. Set the source to the `main` branch and root folder.
5. Save the configuration and wait for GitHub Pages to publish the site.

## Important Pre-Publish Checks

Before publishing publicly:

- Confirm all links work.
- Confirm image paths are case-sensitive and match exactly.
- Confirm the resume PDF is the intended public version.
- Review the Teams alert screenshot for any details you may want to redact.
- Open the site on mobile and desktop.

## Featured Project

The primary case study is **Onyx Auto: End-to-End Data & Analytics Engineering Platform**, a full analytics engineering portfolio project using PHP, MySQL, Airbyte, Snowflake, dbt, Airflow, Docker, Microsoft Teams alerts, and Power BI.
