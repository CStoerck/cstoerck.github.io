### Featured Project

The primary case study is **Onyx Auto: End-to-End Dealership Analytics Engineering Platform**, a recruiter-friendly portfolio write-up converted from the full technical GitHub README. The website version emphasizes the business problem, source-to-dashboard architecture, dbt transformation workflow, Power BI reporting layer, Airflow orchestration, secure credential handling, and skills demonstrated.

### Deployment Instructions

- Upload all root files and the `assets/` folder to the GitHub Pages repository.
- Keep `.nojekyll` in the repository root so GitHub Pages serves the static files directly.
- In GitHub, go to **Settings → Pages**.
- Set the source to the main branch and root folder.
- Save the configuration and wait for GitHub Pages to publish the site.

### Important Pre-Publish Checks

Before publishing publicly:

- Confirm all links work.
- Confirm image paths are case-sensitive and match exactly.
- Confirm the resume PDF is the intended public version.
- Review dashboard and alert screenshots for any sensitive details.
- Open the site on mobile and desktop.
