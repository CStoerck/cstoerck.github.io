This repository contains the static GitHub Pages portfolio website for Cody Stoerck.

#### Website Structure

├── onyx-auto.html
├── netflix-analytics.html
├── styles.css
├── 404.html
├── .nojekyll
└── assets/

#### Featured Project
The primary case study is **Onyx Auto: End-to-End Dealership Analytics Engineering Platform**.

#### Supporting Project
The secondary case study is **Movie Performance Analytics Engineering Pipeline**.

#### Deployment Instructions
- Upload all root files and the assets/ folder to the GitHub Pages repository.
- Keep .nojekyll in the repository root so GitHub Pages serves the static files directly.
- In GitHub, go to **Settings → Pages**.
- Set the source to the main branch and root folder.
- Save the configuration and wait for GitHub Pages to publish the site.
